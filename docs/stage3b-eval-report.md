## 1. 후보 (대국 전에 매개변수 고정, 한 번에 하나만 변경)

기준선: 현재 평가 `d상대 − d자신 + 1.0 × (벽 차이) ± 0.5 (차례)`. 모든 후보는 `MinimaxEvalWeights`의 **선택 필드**로 구현했고, 필드가 없으면 기존과 비트 단위로 같은 값을 냅니다(테스트).

| 후보 | 가설 | 구현 |
|---|---|---|
| **E1** 진행 단계별 벽 가치 | 1단계: AB가 벽을 1–3개 남긴 채 패배 → 손에 든 벽을 과대평가 | k번째 벽 가치 0.85^(k−1)(체감), × min(1, (d자신 + d상대)/10) — 경주가 끝날수록 손에 든 벽의 가치 감소 |
| **E2** 목표 거리별 경로 가중치 | 목표 근처의 1칸이 먼 곳의 1칸보다 중요 | 거리 d 대신 6·ln(1 + d/6) |
| **E3** 경로 취약성 | 벽 한 개로 크게 늘어나는 경로는 위험 | ± 0.5 × (상대 취약성 − 내 취약성). 취약성 = 최단 경로를 끊는 벽 하나가 만드는 최대 우회 증가 |
| **E4** 상대 잔여 벽 × 내 취약성 | 취약성은 상대에게 벽이 있을 때만 위험 | 0.5 × (v상대·min(w자신,3)/3 − v자신·min(w상대,3)/3) |
| **E5** 기보 기반 가중치 학습 | 손으로 정한 가중치의 편향 | 기존 선형 항의 가중치를 실제 승패로 로지스틱 회귀 (3장) |

E3와 E4는 양쪽 벽이 3개 이상이면 같은 값입니다(min(w,3)/3 = 1) — 두 후보의 차이는 벽이 적은 종반에만 나타납니다.

## 3. E5 학습 — 누출 방지 [실측] (`bench/results/stage3b/e5-fit-2026-11-12T04-26-35-809Z.md`)

- 데이터: 1·2단계, 3-A V1/V1b의 기록 대국(결정된 대국) 위치. 특징(차례인 쪽 관점): 1, d상대, d자신, 벽 차이. 정답: 그 대국에서 차례인 쪽이 이겼는가.
- **분할 단위 = 좌우 대칭을 같은 것으로 본 오프닝**: 같은 오프닝의 두 대국, 반복되거나 대칭인 오프닝은 항상 한쪽에만 들어갑니다(학습/검증 오프닝 겹침 0). 검증 국면 중 대칭 포함 같은 국면이 학습에 있으면 제거.
- 결과: 검증 로그 손실 — 상수 0.6931, 현재 가중치(척도만 맞춤) 0.4897, **학습 가중치 0.4557**.
- 학습된 가중치: `{ tempo 0.482, opponentDistance 1, selfDistance 1.001, wallDifference 1.503 }` — 거리·차례는 그대로, **손에 든 벽의 가치만 1.0 → 1.5**. E1의 가설(벽 과대평가)과 반대 방향입니다.
- **주의**: 이 엔진들끼리의 대국 결과를 더 잘 *예측*할 뿐입니다. 벽을 많이 남긴 쪽이 이기는 상관은 "벽을 아끼면 이긴다"는 인과를 뜻하지 않습니다(예: 앞선 쪽은 벽을 쓸 필요가 없음). 그래서 E5도 다른 후보와 똑같이 대국(SPRT)으로만 판정합니다.
- 확인 대국의 오프닝은 학습에 쓴 모든 대국의 오프닝(및 그 이전 모든 실험의 오프닝, 2,247개)과 겹치지 않도록 원장으로 제외했습니다.

- **E1**: 손에 든 벽의 가치를 낮추자 같은 깊이에서 크게 약해졌습니다. 1단계의 "벽을 남긴 채 패배 → 과대평가" 해석은 틀렸습니다. E5 학습 결과(벽 가치 1.0 → 1.5)와도 같은 방향입니다.
