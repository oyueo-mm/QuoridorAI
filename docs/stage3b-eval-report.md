## 1. 후보 (대국 전에 매개변수 고정, 한 번에 하나만 변경)

기준선: 현재 평가 `d상대 − d자신 + 1.0 × (벽 차이) ± 0.5 (차례)`. 모든 후보는 `MinimaxEvalWeights`의 **선택 필드**로 구현했고, 필드가 없으면 기존과 비트 단위로 같은 값을 냅니다(테스트).

| 후보 | 가설 | 구현 |
|---|---|---|
| **E1** 진행 단계별 벽 가치 | 1단계: AB가 벽을 1–3개 남긴 채 패배 → 손에 든 벽을 과대평가 | k번째 벽 가치 0.85^(k−1)(체감), × min(1, (d자신 + d상대)/10) — 경주가 끝날수록 손에 든 벽의 가치 감소 |
| **E2** 목표 거리별 경로 가중치 | 목표 근처의 1칸이 먼 곳의 1칸보다 중요 | 거리 d 대신 6·ln(1 + d/6) |
| **E3** 경로 취약성 | 벽 한 개로 크게 늘어나는 경로는 위험 | ± 0.5 × (상대 취약성 − 내 취약성). 취약성 = 최단 경로를 끊는 벽 하나가 만드는 최대 우회 증가 |
| **E4** 상대 잔여 벽 × 내 취약성 | 취약성은 상대에게 벽이 있을 때만 위험 | 0.5 × (v상대·min(w자신,3)/3 − v자신·min(w상대,3)/3) |
| **E5** 기보 기반 가중치 학습 | 손으로 정한 가중치의 편향 | 기존 선형 항의 가중치를 실제 승패로 로지스틱 회귀 (3장) |

E3와 E4는 양쪽 벽이 3개 이상이면 같은 값입니다(min(w,3)/3 = 1) — 두 후보의 차이는 벽이 적은 종반에만 나타납니다.

## 3. E5 학습 — 누출 방지 [실측] (`bench/results/stage3b/e5-fit-2026-11-12T04-26-35-809Z.md`)

- 데이터: 1·2단계, 3-A V1/V1b의 기록 대국(결정된 대국) 위치. 특징(차례인 쪽 관점): 1, d상대, d자신, 벽 차이. 정답: 그 대국에서 차례인 쪽이 이겼는가.
- **분할 단위 = 좌우 대칭을 같은 것으로 본 오프닝**: 같은 오프닝의 두 대국, 반복되거나 대칭인 오프닝은 항상 한쪽에만 들어갑니다(학습/검증 오프닝 겹침 0). 검증 국면 중 대칭 포함 같은 국면이 학습에 있으면 제거.
- 결과: 검증 로그 손실 — 상수 0.6931, 현재 가중치(척도만 맞춤) 0.4897, **학습 가중치 0.4557**.
- 학습된 가중치: `{ tempo 0.482, opponentDistance 1, selfDistance 1.001, wallDifference 1.503 }` — 거리·차례는 그대로, **손에 든 벽의 가치만 1.0 → 1.5**. E1의 가설(벽 과대평가)과 반대 방향입니다.
- **주의**: 이 엔진들끼리의 대국 결과를 더 잘 *예측*할 뿐입니다. 벽을 많이 남긴 쪽이 이기는 상관은 "벽을 아끼면 이긴다"는 인과를 뜻하지 않습니다(예: 앞선 쪽은 벽을 쓸 필요가 없음). 그래서 E5도 다른 후보와 똑같이 대국(SPRT)으로만 판정합니다.
- 확인 대국의 오프닝은 학습에 쓴 모든 대국의 오프닝(및 그 이전 모든 실험의 오프닝, 2,247개)과 겹치지 않도록 원장으로 제외했습니다.

## 6. E3·E4 비용 분석과 최적화 [실측]

**원인**: 평가마다 각 플레이어의 최단 경로를 끊는 벽 후보(약 11개, 겹침 제외 약 10개)마다 "벽 하나를 더한 BFS"를 실행합니다. 평가 1회 = 기존 BFS 2회 + 추가 BFS 약 20회입니다.

깊이 4 탐색 프로파일(24국면):
- 시간의 약 80%가 추가 BFS(회당 약 1.5 µs)였습니다.
- 경로 계산·후보 생성·충돌 검사는 나머지입니다.
- 평가 호출의 23%는 수 정렬용이었습니다.
- 같은 (벽 배치, 플레이어, 칸)의 취약성 계산이 43% 중복되었습니다.

| 시도 | 결과 | 채택 |
|---|---|---|
| **정확 캐시**: 취약성은 벽 배치와 그 플레이어의 칸에만 의존 → (벽 배치 비트 128개, 칸) 키로 저장. 해시 충돌 없음. 형제 노드의 졸 이동, 상대 수 뒤 변하지 않은 쪽, 전치, 반복 심화의 재방문에 적중 | 탐색 시간 4.6× → 3.3× (노드 수 동일) | ✔ |
| **BFS 재개**: 추가 벽이 끊는 칸의 가장 이른 BFS 층 전까지는 결과가 같음 → 기본 BFS의 층을 한 번 저장하고 그 층부터 이어서 탐색. 마스크 복사·할당 제거 | 취약성 1회 31 → 23 µs | ✔ |
| 필요 없는 쪽 생략: E4는 상대에게 벽이 없으면 내 취약성 항이 0 | 종반에서 절약 | ✔ |
| 수 정렬에만 저렴한 기존 평가 사용 | 3% 절약, 노드 증가 → 캐시가 이미 대부분을 재사용 | ✘ (되돌림) |
| "늘지 않는" 후보 벽을 BFS 없이 판별 | 후보의 73%가 실제로 경로를 늘림 → 최대 27% 절약 대비 복잡도 과다 | ✘ |

정확성 [확인]: 모든 벽 128자리에서 재개 BFS = 기존 함수, 취약성 = 전수 계산(기존 테스트), 캐시가 찬 상태 = 빈 상태의 점수, 탐색 노드 수 동일.

**실제 대국 국면 기준 비용**(`bench/results/stage3b/cost-gate-*.md`, AC 전원):

| | 노드당 비용 | 300 ms 노드 수 | 300 ms 완료 깊이 |
|---|---:|---:|---:|
| E4 최적화 전 (실제 대국 기록) | 5.1× | 0.20× | −2.06 ply |
| E4 최적화 후 (vs v1) | 2.34× | 0.51× | −0.63 ply |
| E6 = E5 + E4 항 (vs E5) | 2.24× | 0.55× | −0.59 ply |

남은 비용(약 2.3×)은 후보 벽마다 BFS를 하는 방식 자체의 비용입니다. 더 줄이려면 취약성을 근사(예: 경로 앞부분만)해야 하는데, 그것은 평가 값이 달라지는 **새 후보**라 새로 검정해야 합니다.

## 7. 후속 실험 [실측] (`bench/results/stage3b/stage3b-next/REPORT.md`, `stage3b-confirm/REPORT.md`)

E6 = 채택된 E5 + E4 항(0.5, 대국 전에 고정). 결합안은 새 후보로 자체 대국을 거칩니다. 오프닝은 3-B까지의 모든 오프닝(3,672개, `ledger-7ca328c9`)과 겹치지 않습니다.

**투입 판단(비용 대비 기대 효과)**:
- E4 자료에서 2.06 ply 손실이 +84를 −14로 바꿨으므로 1 ply ≈ 48 Elo입니다(대략적 값).
- 0.6 ply 손실이면 기대치는 약 +55입니다.
- 비용(예비 15분 + SPRT 1–2.5시간)이 작아 투입했습니다.

| 단계 | 조건 | 결과 |
|---|---|---|
| 비용 관문 | 실제 대국 국면 | 노드당 2.24×, 300 ms에서 −0.59 ply |
| 전술 | E6 / 기본 / v1, 깊이 4·300 ms | 회귀 없음: 세 쪽 모두 132/141, 300 ms 139/141 |
| 예비 P-E6-300 | AC 전원, 40쌍 (3쌍 반복 무승부 제외) | 쌍 점수 **0.500** (0.386–0.614), Elo +5 (−72 … +81), 37쌍 · 수당 노드 6,877 / 12,293, 깊이 7.55 / 8.13 |

**확인 SPRT를 추가한 이유**:
- 예비(AC)와 SPRT(배터리)의 차이가 z ≈ 1.8(p ≈ 0.07)로 우연이라 보기에는 큽니다.
- 배터리에서는 두 쪽 모두 탐색이 얕아지고(7.25 vs 8.13 ply), E4 항은 얕은 탐색에서 가장 강했습니다(깊이 4 +84).
- 따라서 SPRT의 이득이 **전원 상태(=실효 시간)에 의존**할 수 있습니다.
- 기본 AI를 바꾸는 결정을 이 한 번의 결과에 걸면 이득을 과장할 위험이 있어, 같은 기준(H0 0 / H1 +30, α = β = 0.05)으로 새 오프닝에서 한 번 더 검정했습니다.
- 두 결과를 모두 보고합니다.

**판정**: 확인 SPRT도 AC 전원에서 승격(+89)했습니다.
- 배터리 의존이라는 가설은 지지되지 않습니다. 예비 결과(0.500, 37쌍)는 CI가 넓은 작은 표본의 변동으로 봅니다.
- 세 결과를 합친 쌍 점수는 0.600(199쌍)으로 약 +70 Elo입니다. 두 SPRT의 정지 편향 때문에 실제보다 다소 클 수 있습니다.
- 정지 편향을 고려해 보수적으로 읽어도(각 CI 하한 +36, +37) **E6 > E5**입니다. 그래서 E6를 기본값으로 채택했습니다.
- 이 경과는 "소규모 예비 실험이 유의하지 않아도 그것만으로 효과가 없다고 단정하지 않는다"는 원칙의 실제 사례입니다.

## 8. 앞으로의 평가 함수 실험 절차 (3-B에서 얻은 교훈)

3-B에서 대국 계산 시간의 대부분을 쓴 것은 E3(1,200판, 4–5× 비용)이었습니다. 대국 전 비용 분석에서 "깊이 4 이득 최대 +38 vs 2 ply 손실(약 −100)"을 계산했다면 동일 시간에서 이길 가능성이 낮다는 것을 미리 알 수 있었습니다.

1. **비용 관문**(수 분, `bench/eval-cost.bench.test.ts`): 실제 대국 국면에서 노드당 비용과 목표 시간(300 ms)의 예상 깊이 손실을 잽니다. 합성 국면은 쓰지 않습니다(E4 비용을 3.8×로 과소평가했음).
2. **전술 관문**(수 분): 전술 실수 회귀만 확인합니다(세트가 포화되어 강도 순위에는 쓰지 않음).
3. **기대 효과 판단**: 사전 근거(같은 깊이 결과나 학습 검증 손실) − 깊이 손실 × 약 48 Elo/ply. 기대값이 양수이고 실험 비용에 비해 가치가 있으면 투입합니다. 소규모 결과가 유의하지 않다는 이유만으로 버리지 않습니다.
4. **예비 대국**(40쌍, 목표 조건): 버그·명백한 손해만 거릅니다. 규칙은 사전에 고정하고, SPRT에 섞지 않습니다.
5. **본 SPRT**(목표 조건 = 동일 시간): 기준(H0 0 / H1 +30, α = β = 0.05)은 바꾸지 않습니다.
6. 동일 깊이 SPRT는 **비용이 약 1×인 후보의 빠른 선별**에만 씁니다. 그런 후보는 동일 깊이 결과가 동일 시간을 잘 예측합니다(E5: +44 → +55). 비싼 후보는 동일 깊이 결과가 오해를 부릅니다(E4: +84 → −14).

## 9. 통계적 불확실성과 비용 대비 효과

- **Elo 추정치의 편향**: SPRT는 경계를 넘는 순간 멈추므로 보고된 Elo는 극단적인 쪽으로 치우칩니다. E4 +84(89쌍), E6 +86(78쌍)처럼 일찍 끝난 검정일수록 실제 효과는 더 작을 가능성이 큽니다. 판정 근거는 LLR이고, 효과 크기는 CI의 아래쪽을 보수적인 값으로 읽어야 합니다.
- **같은 깊이 ≠ 같은 시간**: 비용이 1×인 E5는 두 조건이 비슷했지만(+44 → +55), 비싼 E4는 정반대였습니다(+84 → −14). 동일 시간 결과만 실제 강도입니다.
- **판단 불가는 미결**: E3(+18, CI −1 … +38)는 효과가 없다는 증거가 아닙니다. 다만 최적화 전 비용(약 5×)으로는 동일 시간에서 이길 가능성이 낮아 재검정 우선순위가 낮습니다.
- **다중 검정**: 3-B에서 7번의 SPRT(F 5, T 2)와 후속 2번을 했습니다. 효과 없는 후보 하나가 잘못 승격될 확률은 검정당 5%입니다. 그래서 채택에는 서로 다른 오프닝의 **두 번의 통과**를 요구했습니다(E5: F+T, E6: T+C).
- **실행 환경**: 배터리 전원에서는 CPU가 느려져 300 ms의 실효 깊이가 약 0.9 ply 얕아집니다. 깊이에 민감한 후보(E4·E6)는 결과가 달라질 수 있습니다. 이후 동일 시간 실험은 AC 전원에서만 시작합니다(`stage3b-confirm-pipeline.ps1`이 배터리면 시작하지 않음).
- **비용 대비 효과**(대국 계산 시간, 4프로세스 기준 대략):

### 10.3 진행 방법 (3-B의 교훈 적용)

0. **기준선**: 새 기본값 E6 vs Guided MCTS(300 ms, 100쌍, AC)를 측정해 3-C의 비교 기준으로 삼습니다(3-B 최종 비교는 E5로 했음).
1. **프로파일 먼저**(수 분): 실제 대국 국면에서 `hashState`·`Map`·`expand`·평가·합법성 검사의 시간 비중을 측정합니다. 2단계의 `expand` 46%는 비트보드 이전 값이라 다시 잽니다.
2. **결과가 같은 최적화**(TT 구조, 증분 해시, PVS, Aspiration, History):
   - 고정 깊이에서 점수·최선 수가 같음을 테스트로 보장하고, 시간 대비 완료 깊이를 측정합니다.
   - 비트보드처럼 "같은 결과, 더 빠름"이면 채택합니다.
   - 묶어서 300 ms SPRT로 최종 확인합니다.
3. **결과가 달라지는 변경**(부분 반복, 수 사이 TT, 깊은 TT 컷오프, LMR):
   - 하나씩 비용 관문 → 전술 → 예비(AC 전원) → SPRT(기준 불변) 순서로 진행합니다.
   - 채택에는 독립 오프닝에서 두 번 통과를 요구합니다.
4. 모든 동일 시간 실험은 **AC 전원**에서만 시작하고, 전원·CPU 사용률을 기록합니다.
