## 요약

- 개선 후보를 **실제 대국 승률**로 승격·기각하는 SPRT를 기존 하네스(쌍 대국·재개·출처 기록)에 통합했습니다. 관측 단위는 **오프닝 쌍**(같은 국면, 선후공 교환)입니다.
- **오류율 검증 [실측]**: 실제 기보에서 추정한 선후공 편향(쌍의 51.8%가 1승 1패)을 넣은 모의실험 1,000회씩 — 참 Elo 0에서 잘못된 승격 **4.0%**(목표 α 5%), 참 Elo +30에서 잘못된 기각 **4.1%**(목표 β 5%).
- **재현성 [실측]**: 같은 설정의 실제 SPRT 두 번(V1·V1b, 새 오프닝)이 결정·LLR·대국 기보까지 **완전히 동일**(45쌍에서 승격, Elo +166, 95% CI +97…+249 — 1단계 다른 오프닝의 +160과 일치).
- **판단 불가 표시**: 600쌍 안에 경계를 넘지 못하면 "inconclusive"로 끝납니다. 기존 2단계 실험 중 S1·S3·S6은 소급 적용 시 **판단 불가**였습니다.
- 2단계 S3에서 일반 승률 CI와 쌍 통계가 다른 이유: 쌍의 76%가 1승 1패라 같은 쌍 두 대국의 상관이 −0.54 → 대국 독립을 가정한 Wilson 구간이 분산을 약 2배 과대평가(5장).
- **귀무 실험 V2 [실측]**: 같은 Alpha-Beta끼리 300 ms — 220쌍에서 **H0 수용(기각)**, LLR −2.95, Elo +8 (95% CI −8 … +23). 모형이 예상한 범위 안의 결과입니다(3.2절).

## 2. SPRT 명세 [확인]

| 항목 | 값 / 규칙 |
|---|---|
| 관측 단위 | 오프닝 쌍. A의 쌍 점수 0(2패) / ½(1승 1패) / 1(2승) — 삼항 분포. 두 대국을 독립으로 세지 않음 |
| 제외 | 중단(반복·최대 ply·시간)이 있는 쌍, 재대국 3회 후에도 의심(수당 예산 3배 초과)인 쌍 — 별도 집계 |
| 가설 (기본값) | H0: Elo = 0, H1: Elo = +30 (로지스틱 Elo, 기대 점수 s(E) = 1/(1+10^(−E/400))) |
| 오류 확률 | α = 0.05 (H0이 참일 때 승격), β = 0.05 (H1이 참일 때 기각) |
| 통계량 | 일반화 로그우도비(GSPRT): 각 가설의 평균 제약 아래 삼항 분포 최대우도 추정(Fishtest의 오각 분포 SPRT와 같은 방식). 빈 범주는 10⁻³ 의사 관측으로 정칙화. 정규 근사 LLR을 함께 계산해 교차 확인 |
| 경계 | 승격: LLR ≥ ln((1−β)/α) = +2.944, 기각: LLR ≤ ln(β/(1−α)) = −2.944 |
| 최소 대국 | 30쌍(60판) 전에는 결정하지 않음 |
| 최대 대국 | 600쌍(1,200판). 도달 시 **판단 불가(inconclusive)** — 승격도 기각도 아님 |
| 결정 시점 | 쌍 번호 순서로 **연속 완료된 접두부**만 사용 → 어느 샤드가 먼저 끝났는지와 무관, 재실행 시 같은 결정. 결정 후 실행 중이던 쌍은 기록되지만 결정에 쓰지 않음 |
| 보고 | 결정, LLR, 사용한 쌍, LL/split/WW, 쌍 점수와 95% CI, Elo와 CI |

설정은 실험(matchup)별로 바꿀 수 있습니다(`Matchup.sprt`, 예: 회귀 검사용 H0 −10 / H1 +10).

## 3. 검증 [실측]

### 3.1 모의실험 (`bench/results/stage3a/validation-2026-11-12T03-38-18-936Z.md`)

실제 1,281쌍의 1승 1패 비율 51.8% → 오프닝 선후공 편향 σ ≈ 75 Elo로 모형화(같은 실력이면 52.2%가 1승 1패). 각 1,000회.

| 참 Elo | 승격 | 기각 | 판단 불가 (600쌍) | 평균 쌍 수 | 90% 분위 |
|---:|---:|---:|---:|---:|---:|
| −30 | 0.1% | 99.9% | 0.0% | 133 | 220 |
| **0** | **4.0%** (≤ α 5%) | 82.6% | 13.4% | 320 | 600 |
| +10 | 18.5% | 48.3% | 33.2% | 406 | 600 |
| +15 | 32.3% | 32.0% | 35.7% | 414 | 600 |
| +20 | 49.3% | 16.4% | 34.3% | 408 | 600 |
| **+30** | 81.5% | **4.1%** (≤ β 5%) | 14.4% | 313 | 600 |
| +45 | 99.0% | 0.1% | 0.9% | 196 | 342 |

- 잘못된 결정은 목표 이하입니다. 표본 오차 ±1.4%p.
- **주의**: 600쌍 상한 때문에 H0·H1에서도 약 14%가 판단 불가로 끝나고, +30에서의 승격 확률(검정력)은 81.5%입니다. 평균 비용은 약 320쌍(640판) — 300 ms에서 4프로세스 약 45분(AC 전원 기준 [추정]).
- 0과 +30 사이의 실제 차이(+10~+20)는 상당수가 판단 불가로 끝납니다. **판단 불가는 "효과 없음"도 "+30 미만"도 아닙니다** — 참 Elo가 +30이어도 14.4%가 판단 불가로 끝나고, 0이어도 13.4%가 그렇습니다. 데이터가 두 가설을 구별하지 못했다는 뜻일 뿐입니다.
- 단위 테스트(`src/arena/__tests__/sprt.test.ts`)가 같은 성질을 더 작은 규모로 매번 검사합니다(α·β 상한, 첫 경계 통과에서 정지, 이후 쌍이 결정을 바꾸지 않음, 상한에서 판단 불가).

### 3.2 실제 대국 (`bench/results/stage3a/stage3a/`, 새 오프닝)

| 실험 | 결정 | 쌍 (LL/split/WW) | LLR | 쌍 점수 (95%) | Elo (95%) |
|---|---|---|---:|---|---|
| V1 AB 깊이 3 vs 2 (고정 예산) | **승격** | 45 (2/21/22) | 3.02 | 0.722 (0.637–0.808) | +166 (+97 … +249) |
| V1b 같은 설정 반복 | **승격** — V1과 완전히 동일 | 45 (2/21/22) | 3.02 | 0.722 | +166 |

- 재현성: V1·V1b의 116판 기보(결정 후 진행된 13쌍 포함)가 수 단위까지 같았습니다.
- **V2 해석**:
  - 실행 환경: 커밋 e8e0eea(src 미수정), **배터리 전원**, 4프로세스, 대국 중 기계 CPU 사용률 평균 57%(최대 84%). 의심 대국 6판(수당 예산 3배 초과)은 같은 일정·시드로 자동 재대국되어 최신 시도만 집계 — 재대국 기능이 실제로 작동함을 확인.
  - 같은 엔진끼리라 쌍의 **89%가 1승 1패**(선후공이 결과를 결정)였습니다. 모의실험이 가정한 52%보다 높지만, GSPRT는 분산을 데이터에서 추정하므로 결론은 유효하고 오히려 빨리 끝납니다(220쌍, 모의 평균 320쌍).
  - A 쪽 점수 0.511(+8 Elo)은 0을 포함하는 신뢰구간 안의 무작위 변동입니다.
  - 모형상 귀무에서 H0 수용 확률 약 83%, 판단 불가 13%, 잘못된 승격 4%. **실험 1회로 α를 검증할 수는 없습니다** — 이번 결과는 그 예상과 일치할 뿐이며, α·β 자체는 3.1절 모의실험(각 1,000회)이 근거입니다. 같은 귀무 실험을 많이 반복해도 약 4%는 잘못 승격될 것으로 예상합니다.

## 4. 오프닝 다양성과 편향 [실측]

- 기존 기본값(6 ply mixed, 정확히 같은 국면만 중복 제거)에서도 좌우 대칭 국면이 실험당 최대 3%(100쌍 중 97–100개 고유) 섞여 있었습니다.
- 새 정책(`openingDedupe: 'mirror'`, 길이 4–8 ply, 경로 차 ≤ 2): 600쌍 모두 대칭 포함 고유, **97%가 이전 18개 실험에서 한 번도 나오지 않은 국면**. 기존 실험의 일정은 바뀌지 않습니다(옵션이 기본값 아님 — 재현성 보존).
- 선공 승률: 실험별 35–60%, 대부분 CI가 50% 포함 — 체계적 선공 이점은 확인되지 않음. 1승 1패 쌍 비율은 9%(AB vs Pure, 실력 차 큼)–76%(S3)로 실력 차가 작을수록 높음.
- 신규성은 `bench/stage3a.bench.test.ts` 4절이 매번 계산합니다.

## 5. 2단계 S3: 일반 승률 CI와 쌍 통계가 다른 이유 [실측]

| 지표 | S3 (path-defense vs 기존, 같은 깊이 4) |
|---|---|
| 대국 단위 | 200판 중 112승 = 56.0%, Wilson 95% 49.1–62.7%, 양측 p = 0.090 |
| 쌍 분포 | 2패 6 / 1승 1패 76 / 2승 18 |
| 같은 쌍 두 대국의 상관 | **−0.54** (오프닝이 한쪽 자리를 크게 유리하게 만듦) |
| 쌍 단위 | 평균 0.560, 95% 0.513–0.607, p = 0.012 |
| 부호 검정 (2승 18 vs 2패 6) | p = 0.023 |
| SPRT (H0 0 / H1 +30) | 판단 불가 — LLR 2.88 (승격 경계 2.94) |

- Wilson 구간은 200판이 **서로 독립**이라고 가정합니다. 쌍 설계에서는 같은 오프닝의 두 대국이 강한 음의 상관(한 판 이기면 다른 판은 지는 경향)을 가져, 쌍 평균의 실제 분산은 독립 가정의 0.46배(설계 효과)입니다. 따라서 Wilson 구간은 **너무 넓고**, 쌍 단위 구간이 이 설계에 맞는 추정입니다.
- 다만 "0과 다르다"(쌍 p = 0.012)와 "개선이 +30 Elo 수준이다"(SPRT)는 다른 질문입니다. S3는 첫 질문에는 예, 둘째에는 아직 판단 불가입니다. 2단계 보고서의 "쌍 점수 CI가 0.5를 넘는다"는 서술은 맞지만, 채택 결정은 같은 시간 결과(S2·S6) 기준이므로 바뀌지 않습니다.
- 앞으로 모든 판정은 쌍 단위(SPRT)로 하고, 대국 단위 Wilson 구간은 참고용으로만 표시합니다.

## 6. 장시간 실행 안전장치 [확인]

| 위험 | 대응 |
|---|---|
| 절전·정지 | `run-shards.ps1`이 절전 방지 도우미 자동 실행(덮개 닫힘은 막지 못함). 수당 예산 3배 초과 대국은 **의심**으로 표시, 같은 일정·시드로 최대 3회 재대국(새 줄 추가, 기존 줄 유지), 분석은 최신 시도만 사용 |
| 비정상 종료 | 대국 1판 단위로 JSONL에 추가 → 같은 명령 재실행 시 완료 대국 건너뜀, 설정 해시가 다르면 거부 |
| 시스템 부하 | 대국마다 기계 전체 CPU 사용률 기록(`cpuBusy`), 세션마다 전원(배터리/AC) 기록 — 보고서에 표시 |
| 중복 대국 | 쌍 번호로 샤드 분할 + 인덱스별 최신 시도만 집계 |
| 부하 중 결과 비교 | 동일 시간 대국은 같은 대국 안 두 에이전트가 같은 조건 → 공정. 대국 간 nodes/s는 비교하지 않음 |

**확인된 환경 문제**: 이 작업 중 노트북이 **배터리로 동작**(방전 중, 69%)했고 같은 테스트가 AC 때보다 약 2.5배 느렸습니다. 장시간 동일 시간 실험은 AC 전원 연결을 권장합니다. 이 때문에 `npm test`의 기존 장애물 지도 테스트(단독 22.5초, 제한 30초)가 새 실제 대국 테스트와 병렬로 돌 때 시간 초과가 나서, 실제 대국을 두는 SPRT 실행기 통합 테스트는 bench 설정(`bench/sprt-runner.integration.test.ts`)으로 옮겼습니다(검증 시 별도 실행, 통과).

## 8. 순차 검정의 통계적 위험 검토

| 위험 | 내용 | 대응 |

| 조기 종료(반복 엿보기) | 고정 표본 검정을 대국마다 반복 확인하면 오류율이 부풀지만, SPRT는 매 쌍 확인을 전제로 경계를 정한 방법이라 α·β가 유지됨(모의실험 확인) | 결정은 SPRT 경계로만. 고정 표본 p값으로 중간에 멈추지 않음 |
| 정지 시점의 추정 편향 | 경계를 넘은 순간에 멈추므로 그 시점의 Elo 추정은 실제보다 극단적인 쪽으로 치우치고, 단순 신뢰구간은 정확한 포함 확률을 보장하지 않음 | 보고되는 Elo·CI는 참고값. 판정 근거는 LLR. 효과 크기는 별도 고정 표본 확인이 필요 |

## 9. 3-B 평가 함수 개선 실험 계획 (제안)

근거: 1단계에서 같은 고정 예산에 AB가 Guided MCTS에 −185 Elo(노드당 판단력), 벽을 1–3개 남긴 채 패배; 2단계에서 탐색 속도 개선만으로는 검출 가능한 승률 차이가 없었음.
기준선은 현재 `createDistanceEvaluator`(d상대 − d자신 + 벽 차이 × 1.0 ± 템포 0.5). **평가 함수는 결정적이어야 함**(TT·재현성).

| 후보 | 내용 | 가설 |
|---|---|---|
| E1 벽 가치의 상황 의존 | 벽 1개의 가치를 남은 경주 길이·상대 벽 수에 따라 변화(초반 높고 종반 실제 사용 가능성에 비례), 체감(오목) 함수 | AB가 벽을 남긴 채 지는 문제 |
| E2 경주 차이의 비선형화 | 남은 거리가 짧을수록 1칸 차이의 가치 증가(예: d차이 / (min(d)+k)) | 종반 판단 강화 |
| E3 경로 취약성 | 자기·상대 최단 경로의 대체 경로 길이(최단 경로 한 변 차단 후 거리), 병목 수 — 비트보드 BFS로 계산 | 벽 한 개로 크게 늘어나는 경로의 위험 반영 |
| E4 상대 벽 위협 | 상대 남은 벽 수 × 내 경로 취약성 | 벽 보유량의 실제 위협 |
| E5 가중치 적합 | 1·2단계 기보 2,800판의 국면과 실제 승패로 로지스틱 회귀(Texel 방식) — 학습/검증 분할 | 수동 가중치의 편향 제거 |

절차(후보마다 독립 실험, 한 번에 하나만 변경):
1. 단위 테스트: 결정성, 대칭(좌우 반전·선후공 관점), 기존 대비 비용(µs/평가).
2. 전술 세트 226국면: 정답 범주 퇴보 없음.
3. **고정 깊이 SPRT**(깊이 4, H0 0 / H1 +30): 비용 차이를 제외한 판단 품질 — 결정적이라 빠름(수 분).
4. 통과 시 **동일 시간 SPRT**(300 ms, H0 0 / H1 +30, 새 mirror 오프닝): 비용을 포함한 실제 강도 — 약 45–90분/후보, AC 전원.
5. 승격된 후보만 기본값 후보로 누적, 최종 조합을 다시 동일 시간 SPRT로 확인(+ Guided MCTS 상대 회귀 검사: H0 −20 / H1 0 — H1 수용 = 퇴보 없음).
판단 불가는 "정해진 표본으로 H0와 H1을 구별하지 못함"으로 기록하고(효과 없음·+30 미만으로 단정하지 않음) 기본값을 바꾸지 않습니다.
