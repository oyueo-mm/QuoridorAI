# Heuristic-Guided MCTS — 단계별 개선 요약

원자료: `step-A.{md,jsonl}`, `step-B.{md,jsonl}`, `step-C.{md,jsonl}` (각 단계 별도 저장, 기존 벤치마크 파일은 수정하지 않음).
하네스: `bench/mcts-improvement.test.ts` (`BENCH_STEP=A|B|C`).

## 공통 조건

- 시간 예산: 결정당 200 ms (시뮬레이션 횟수 무제한), 시드 1·2·3
- 포지션: **튜닝 세트** 5개(진단에 사용한 시작·오프닝 포지션), **검증 세트** 6개(이번에 처음 사용 — 오프닝 3 + BFS 자가대국 중반 3)
- Alpha-Beta 손실: Alpha-Beta 깊이 4의 최선 수 가치 − MCTS가 둔 수 이후 깊이 3 가치 (MCTS 관점). Alpha-Beta 자신의 평가를 기준으로 한 **대리 지표**이며, 평가 함수 컷오프를 쓰는 설정에 유리하게 작용할 수 있음.
- 대국: Alpha-Beta 200 ms 상대, 오프닝 (0,0)·(1,2)[튜닝] + (10,2)[검증] × 선후공 = 6판, 최대 200 ply, 같은 포지션 3회 반복 시 중단.
- 절전(결정이 예산의 5배 초과) 의심 결정: 모든 단계에서 0건.

## A. 평가 함수 컷오프 (롤아웃 0 / 2 / 4 ply, UCT)

| 설정 | 손실 튜닝 / 검증 | 최선 수 일치 (검증) | 시뮬레이션/결정 (검증) | 대국 W-L |
|---|---|---|---:|---|
| Pure (기준) | 1.00 / 0.89 | 5/18 | 72 | 0-6 |
| 컷오프 0 ply | 0.00 / 0.11 | 16/18 | 5,447 | 0-6 |
| 컷오프 2 ply | 0.00 / 0.28 | 13/18 | 1,401 | 0-6 |
| 컷오프 4 ply | 0.07 / 0.33 | 12/18 | 856 | 2-4 |

- 대리 지표는 0 ply가 가장 좋지만, 0 ply MCTS는 Alpha-Beta와 같은 평가식을 거의 그대로 근사하므로 이 지표에서 유리할 수밖에 없다.
- 실제 대국에서 이긴 것은 4 ply뿐이었다(6판 중 2승). 짧은 롤아웃이 평가식이 못 보는 단기 상호작용(벽 대응 등)을 일부 반영한 것으로 보인다.
- **선택: 4 ply** (실제 결과 우선). 표본이 작아 0/2/4 간 대국 차이는 통계적으로 확정적이지 않다.

## B. PUCT + 휴리스틱 사전 확률 (A = 4 ply)

| 설정 | 손실 튜닝 / 검증 | 1위 방문 비율 | 방문 엔트로피 | 최대 트리 깊이 | 시뮬레이션/결정 | 대국 W-L |
|---|---|---:|---:|---:|---:|---|
| UCT | 0.07 / 0.33 | 12% / 24% | 4.09 / 3.36 비트 | 3.1 / 4.7 | 502 / 850 | 1-5 |
| PUCT | 0.00 / 0.28 | 75% / 71% | 1.65 / 1.56 비트 | 11.0 / 10.5 | 369 / 621 | 1-5 |

- 방문이 유망한 수에 집중되고(엔트로피 4.1 → 1.6비트) 트리가 3배 이상 깊어졌다. 사전 확률 계산 비용으로 시뮬레이션 수는 25% 정도 줄었다.
- 33개 결정 중 31개는 같은 수, 달라진 2개는 모두 PUCT 쪽이 손실 1.00 → 0.00으로 개선(UCT에서는 1·2위 방문이 동률이던 경우).
- 대국은 동일(1-5). **선택: PUCT 적용** — 탐색 효율과 결정 품질 개선, 대국 퇴보 없음.

## C. 가치 포화 완화 (A = 4 ply, B = PUCT)

| 설정 | 손실 튜닝 / 검증 | 최선 수 일치 (검증) | 1위 방문 비율 | 대국 W-L (튜닝 / 검증) |
|---|---|---:|---:|---|
| 완화 없음 | 0.00 / 0.28 | 13/18 | 78% / 71% | 3-1 / 0-2 |
| 완화 적용 | 0.00 / 0.22 | 14/18 | 63% / 57% | 4-0 / 0-2 |

- 실제 승패의 일관성: 트리 안의 종료·증명 노드는 정확히 ±1, 롤아웃 안에서 끝난 승리는 ±(0.9~1), 모든 추정값은 |v| < 0.9 (단위 테스트로 보장).
- 일방적인 포지션에서도 추정값 기울기가 유지되어(−16 vs −18 걸음: tanh 차이 < 0.001, 완화 후 > 0.01) 탐색이 조금 더 넓어지고 검증 세트 손실이 소폭 개선.
- **선택: 적용** — 소폭 개선, 퇴보 없음.

## 해석 시 주의

- 같은 설정(A4 + PUCT)이 단계 B에서 1-5, 단계 C에서 3-3을 기록했다. 200 ms 시간 제한 대국은 기계 부하에 따라 시뮬레이션 수가 달라져 비결정적이며, 6판 표본에서는 ±2승 정도의 잡음이 있다. 대국 결과의 단계 간 차이는 경향으로만 해석해야 한다.
- 대리 지표(Alpha-Beta 손실)와 실제 대국 결과가 항상 일치하지는 않는다(A 단계의 0 ply).
- 개선 후 Guided MCTS는 Alpha-Beta와 대등한 수준에 근접했지만(완화 적용: 4-2), 확정하려면 더 큰 표본이 필요하다 — 다음 단계(AI vs AI Arena)에서 다룬다.

## 최종 기본값

| | Pure MCTS (보존) | Guided MCTS |
|---|---|---|
| 선택 규칙 | UCT, C = 1.4 | PUCT, c = 1.5, 사전 확률 softmax(1수 평가, τ = 1) |
| 리프 평가 | 휴리스틱 롤아웃 최대 100 ply, 거리 추정 컷오프 | 휴리스틱 롤아웃 4 ply + Minimax 평가 컷오프 |
| 가치 | 승패 ±1, 추정 tanh | 가치 포화 완화(추정 < 0.9 < 롤아웃 승리 ≤ 1 = 종료) |
| 예산 | 3,000회 / 2,000 ms | 20,000회 / 2,000 ms |
